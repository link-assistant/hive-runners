Ship the Hive Runners CLI, Minikube and ARC deployment, VPS fleet control plane, and metered runner portal with supplier routing.

Store the control-plane ledger with Link CLI, support Links Notation in first-party interfaces, and provide configurable UI templates, optional Prometheus and Grafana dashboards, and opt-in ARC container modes.

Deploy GitLab and GitHub pools alongside each other on Linux hosts, expose NVIDIA GPUs to jobs, and calculate CPU, memory, storage and GPU capacity. Support GitHub App, PAT and authenticated gh sessions, reserve capacity for active accounts, and match wholesale purchases to exact resource profiles with prepaid execution caps.
