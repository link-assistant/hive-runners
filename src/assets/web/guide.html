H Hive Runners
Runner portal

Deploy a fleet

Start with one private repository and an Ubuntu host. Use your runner pool label in the workflow. 

hive-runners init
hive-runners render
hive-runners deploy --inventory inventory.json

Connect GitHub

Install the GitHub App for the repository or organization. Supply its ARC credentials and a GitHub administration token to the deployment process.

Enable on-demand capacity

Configure a provider, subscribe to GitHub workflow-job events, and run the control plane to add machines when jobs queue up.
