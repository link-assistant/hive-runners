# Hive Runners CLI reference

Generated by `hive-runners docs`. Command options use the long forms below.
The default configuration is `hive-runners.lino`. Use `--json` for JSON command output.

## init

Write an example runner configuration.

```text
hive-runners init [--config FILE]
```

## render

Write Terraform, Ansible and runner chart values under hive-managed.

```text
hive-runners render [--config FILE] [--directory DIR]
```

## deploy

Deploy GitHub and GitLab pools to SSH inventory hosts, optionally after applying Terraform.

```text
hive-runners deploy [--config FILE] (--inventory FILE | --apply-infra) [--directory DIR]
```

## capacity

Calculate job requirements and minimum and recommended machine capacity.

```text
hive-runners capacity [--config FILE] [--shared POOL[,POOL]]
```

## proposal

Push an isolated configuration branch and open a draft pull request.

```text
hive-runners proposal [--config FILE] [--base BRANCH] [--branch hive/NAME]
```

## github-runners

List GitHub self-hosted runners.

```text
hive-runners github-runners --scope ORG[/REPO]
```

## github-groups

List GitHub organization runner groups.

```text
hive-runners github-groups --scope ORG
```

## github-group

Configure a runner group for selected private repositories.

```text
hive-runners github-group --scope ORG --name GROUP --repositories REPO[,REPO]
```

## github-labels

Replace the custom labels on a directly registered runner.

```text
hive-runners github-labels --scope ORG[/REPO] --id RUNNER_ID --labels LABEL[,LABEL]
```

## gitlab-runners

List runners for a private GitLab project or group.

```text
hive-runners gitlab-runners --scope PATH [--kind project|group] [--origin HTTPS_URL]
```

## gitlab-create

Create a private, tag-only GitLab runner and print its one-time credential.

```text
hive-runners gitlab-create --scope PATH --name TAG [--kind project|group] [--origin HTTPS_URL]
```

## gitlab-tag

Replace a GitLab runner’s tags with the configured tag and disable untagged jobs.

```text
hive-runners gitlab-tag --id RUNNER_ID --name TAG [--origin HTTPS_URL]
```

## provider-list

List compute instances through the configured provider API.

```text
hive-runners provider-list --name PROVIDER [--config FILE]
```

## account-offer

Show the runner pool and its credit.

```text
hive-runners account-offer --origin HTTPS_URL
```

## account-activate

Activate the runner pool for up to one hour.

```text
hive-runners account-activate --origin HTTPS_URL --minutes MINUTES [--max-cents CENTS]
```

## account-stop

End the runner pool activation.

```text
hive-runners account-stop --origin HTTPS_URL
```

## account-checkout

Start a Stripe Checkout session to add runner credit.

```text
hive-runners account-checkout --origin HTTPS_URL --cents CENTS --request-id UUID
```

## serve

Start the fleet reconciler, landing page, and optional customer portal.

```text
hive-runners serve [--config FILE]
```

## migrate-state

Import a stopped installation’s SQLite ledger into a new Links store.

```text
hive-runners migrate-state --from SQLITE_FILE --state DIRECTORY
```

## docs

Generate the Markdown reference from this command registry.

```text
hive-runners docs [--output FILE]
```
