# Hive Runners CLI reference

Generated by `hive-runners docs`. Command options use the long forms below.

## init

Write an example runner configuration.

```text
hive-runners init [--config FILE]
```

## render

Write Terraform, Ansible and ARC files under hive-managed.

```text
hive-runners render [--config FILE] [--directory DIR]
```

## deploy

Deploy ARC to SSH inventory hosts or explicitly apply Terraform first.

```text
hive-runners deploy [--config FILE] (--inventory FILE | --apply-infra) [--directory DIR]
```

## proposal

Push an isolated configuration branch and open a draft pull request.

```text
hive-runners proposal [--config FILE] [--base BRANCH] [--branch hive/NAME]
```

## github-runners

List GitHub self-hosted runners.

```text
hive-runners github-runners --scope ORG[/REPO]
```

## github-groups

List GitHub organization runner groups.

```text
hive-runners github-groups --scope ORG
```

## github-group

Configure a runner group for selected private repositories.

```text
hive-runners github-group --scope ORG --name GROUP --repositories REPO[,REPO]
```

## github-labels

Replace the custom labels on a directly registered runner.

```text
hive-runners github-labels --scope ORG[/REPO] --id RUNNER_ID --labels LABEL[,LABEL]
```

## provider-list

List compute instances through the configured provider API.

```text
hive-runners provider-list --name PROVIDER [--config FILE]
```

## serve

Start the fleet reconciler, landing page, and optional customer portal.

```text
hive-runners serve [--config FILE]
```

## docs

Generate the Markdown reference from this command registry.

```text
hive-runners docs [--output FILE]
```
